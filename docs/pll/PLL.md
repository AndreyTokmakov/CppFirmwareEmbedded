# Что такое PLL

**PLL (Phase-Locked Loop)** — система автоматического управления, которая заставляет один генератор повторять частоту и фазу другого генератора.

Простыми словами:

> PLL умеет из стабильного эталонного сигнала получить другую частоту, сохраняя высокую точность.

Например:

```
Reference Clock
      |
   40 MHz
      |
     PLL
      |
   2.4 GHz
```

Или

```
25 MHz кварц
      |
     PLL
      |
100 MHz CPU clock
```

Или

```
10 MHz OCXO
      |
     PLL
      |
915 MHz LO
```

---

# Где используется PLL

Практически везде.

### CPU

Процессор обычно получает внешний кварц

```
Crystal
16 MHz
```

но работает на

```
1.6 GHz
```

Как?

```
16 MHz
   |
 PLL
   |
1.6 GHz
```

Без PLL пришлось бы использовать кварц на 1.6 GHz, что невозможно.

---

### SDR

Например AD9361.

Есть

```
40 MHz reference
```

а необходимо получить

```
70 MHz
915 MHz
2.45 GHz
6 GHz
```

Все это делает PLL.

---

### Ethernet

Например

```
25 MHz crystal
```

↓

```
125 MHz
```

для Gigabit Ethernet.

---

### USB

USB требует очень точных

```
48 MHz
```

Поэтому почти каждый STM32 имеет PLL.

---

### PCIe

```
100 MHz
```

↓

```
2.5 GHz
5 GHz
8 GHz
16 GHz
```

---

### HDMI

PLL генерирует Pixel Clock.

---

### RF

Практически любой трансивер содержит PLL.

Например

```
LO = 2.412 GHz
```

получается именно PLL.

---

# Основные элементы PLL

Классическая схема выглядит так

```
             +----------------+
             |                |
Reference ---> Phase Detector +----+
             |                |    |
             +----------------+    |
                                   |
                              Loop Filter
                                   |
                                   |
                             Voltage Control
                                   |
                             +-------------+
                             |             |
                             |    VCO      |
                             |             |
                             +-------------+
                                   |
                                   |
                              Output Clock
                                   |
                                   |
                              Frequency Divider
                                   |
                                   +-------------+
```

Всего четыре основных блока.

---

## 1. Reference

Это максимально стабильный источник.

Например

```
Crystal

TCXO

OCXO

GPSDO
```

Например

```
10 MHz
```

---

## 2. Phase Detector (PFD)

Он сравнивает

```
Reference
```

и

```
Feedback
```

не по величине,

а именно по фазе.

Например

```
Reference

|_|_|_|_|_|_|

Feedback

 |_|_|_|_|_|_|
```

Feedback немного опаздывает.

PFD понимает

```
Нужно увеличить частоту.
```

Если наоборот

```
 |_|_|_|_|_|_|

|_|_|_|_|_|_|
```

значит нужно уменьшить.

---

## 3. Loop Filter

После PFD получается "дерганый" сигнал.

Loop Filter его сглаживает.

Чаще всего это

```
RC фильтр
```

или активный фильтр.

---

## 4. VCO

Voltage Controlled Oscillator.

Это генератор,

частота которого зависит от напряжения.

Например

```
0.5 V → 900 MHz

1.0 V → 910 MHz

1.5 V → 920 MHz

2.0 V → 930 MHz
```

Loop Filter меняет напряжение,

VCO меняет частоту.

---

# Как работает PLL

Допустим

Reference

```
10 MHz
```

а нужно

```
100 MHz
```

Имеется делитель

```
÷10
```

Получается

```
Reference
10 MHz

VCO
100 MHz

↓

Divider

10 MHz
```

PFD сравнивает

```
10 MHz

и

10 MHz
```

Пока они не совпадут по фазе,

PLL постоянно регулирует VCO.

Когда совпали —

говорят

```
PLL Locked
```

---

# Почему нужен Divider

Без него PLL могла бы генерировать только

```
Reference = Output
```

Делитель позволяет получать любую кратную частоту.

Например

```
Reference = 10 MHz

Divider = 100

Output = 1 GHz
```

---

# Формула

Самая простая

```
Fout = Fref × N
```

где

```
N
```

коэффициент деления.

---

Например

```
10 MHz

N = 50

↓

500 MHz
```

---

# Fractional-N PLL

Современные PLL умеют

```
N = 100.25
```

или

```
N = 52.125
```

Получается

```
Fout = Fref × 52.125
```

Это позволяет получать практически любую частоту.

Именно поэтому современные RF-чипы (например AD9361, ADF4351, ADF4371) могут перестраиваться с шагом в единицы герц или десятки герц, хотя опорный генератор имеет частоту в десятки мегагерц.

---

# Lock Time

PLL не переключается мгновенно.

Например

```
915 MHz

↓

2.4 GHz
```

нужно время.

Это называется

```
Lock Time
```

обычно

```
10 us

100 us

1 ms
```

в зависимости от PLL.

---

# Phase Noise

Самая важная характеристика RF PLL.

Даже идеальный кварц имеет шум.

PLL тоже добавляет шум.

Получается

```
Reference Noise

+

VCO Noise

+

Divider Noise

+

PFD Noise
```

Именно поэтому дорогие генераторы стоят тысячи долларов.

---

# Jitter

В цифровом мире чаще говорят не о фазовом шуме, а о джиттере.

Например

идеальный период

```
10 ns
10 ns
10 ns
10 ns
```

реальный

```
9.98
10.02
9.99
10.03
```

Это и есть

```
Clock Jitter
```

Высокий джиттер может приводить к ошибкам передачи данных, снижению точности АЦП/ЦАП и ухудшению качества высокоскоростных интерфейсов.

---

# PLL в AD9361

В AD9361 используется несколько независимых PLL.

Упрощенно:

```
40 MHz Reference
          |
   +------+------+
   |             |
 RX Synth PLL    |
                 |
 TX Synth PLL    |
                 |
 BBPLL ----------+
```

* **BBPLL (Baseband PLL)** — генерирует внутренние высокочастотные тактовые сигналы для цифровой обработки.
* **RX Synthesizer PLL** — формирует локальный гетеродин для приемника.
* **TX Synthesizer PLL** — формирует локальный гетеродин для передатчика.

Это позволяет независимо настраивать частоты приема и передачи в поддерживаемом диапазоне.

# Что важно знать Embedded/Firmware разработчику

При работе с PLL вы обычно не проектируете аналоговую часть, но должны понимать, как ее правильно настраивать и какие ограничения учитывать:

* Инициализация PLL: запись регистров, запуск и ожидание состояния **Lock**.
* Выбор источника опорной частоты (кварц, TCXO, внешний генератор).
* Настройка множителей и делителей для получения нужной частоты.
* Контроль времени захвата (Lock Time) при смене частоты.
* Проверка статуса блокировки перед началом работы периферии.
* Понимание влияния джиттера и фазового шума на АЦП, ЦАП, RF-тракт и высокоскоростные интерфейсы.
* Для RF-устройств — понимание ограничений по шагу перестройки, времени синтеза и требованиям к качеству опорного генератора.

Понимание принципов работы PLL особенно важно при разработке под SDR, микроконтроллеры, SoC, FPGA и высокоскоростные интерфейсы, поскольку ошибки в настройке тактирования могут приводить к нестабильной работе всей системы.
