**LNA (Low Noise Amplifier)** — это **малошумящий усилитель**. В RF системах это один из самых важных блоков в **приёмном тракте (receiver chain)**.

Простое определение:

> **LNA — это усилитель, который усиливает очень слабый радиосигнал, добавляя как можно меньше собственного шума.**

---

# 1. Зачем нужен LNA

Представим приёмник:

```
Антенна
   |
   |
   v
  LNA
   |
   |
   v
 Mixer
   |
   |
   v
 ADC
   |
   |
   v
 FPGA
```

Сигнал с антенны может быть очень слабым:

Например:

```
Антенна:

-110 dBm
```

Это практически уровень шума.

Если просто подать его дальше:

```
Antenna
   |
   v
 Mixer
```

следующие блоки добавят шум, и сигнал может потеряться.

Поэтому первым активным элементом ставят LNA:

```
-110 dBm

    |
    v

  LNA

    |
    v

-90 dBm
```

---

# 2. Почему именно Low Noise

Любой усилитель добавляет шум.

Идеальный усилитель:

```
Input:
Signal + Noise

       |
       v

Output:

Amplified Signal + same Noise
```

Реальный:

```
Input:

Signal + Noise


       |
       v

      LNA


Output:

Amplified Signal
+
Amplified Noise
+
LNA Noise
```

Задача LNA:

минимизировать:

```
собственный шум усилителя
```

---

# 3. Основной параметр LNA — Noise Figure (NF)

**Noise Figure (NF)** показывает, насколько усилитель ухудшает отношение сигнал/шум.

Измеряется в dB.

Например:

## Хороший LNA:

```
NF = 0.8 dB
```

## Плохой:

```
NF = 5 dB
```

Меньше — лучше.

---

Пример:

На входе:

```
Signal / Noise = 20 dB
```

LNA:

```
NF = 1 dB
```

После:

```
SNR ≈ 19 dB
```

Потеряли только 1 dB.

Другой усилитель:

```
NF = 6 dB
```

Получаем:

```
SNR ≈ 14 dB
```

---

# 4. Почему LNA ставят первым

Есть фундаментальный закон RF:

## Формула Фрииса (Friis Equation)

Для цепочки усилителей:

```
Antenna

 |
 |
LNA
 |
 |
Mixer
 |
 |
ADC
```

общий шум:

[
F_{total}=F_1+\frac{F_2-1}{G_1}+\frac{F_3-1}{G_1G_2}
]

Где:

* F — noise factor
* G — gain

Первый элемент доминирует.

Поэтому:

```
плохой первый блок
=
плохой весь приёмник
```

# 5. Основные параметры LNA

## 1. Gain (усиление)

Например:

```
Gain = 20 dB
```

Если:

```
Input:

-100 dBm
```

то:

```
Output:

-80 dBm
```

---

## 2. Noise Figure

Например:

```
NF = 1.2 dB
```

Главный параметр.

---

## 3. Linearity

Очень важна.

Показывается параметрами:

* IP1dB
* OIP3

---

## IP1dB

Точка, где усилитель начинает насыщаться.

Например:

```
Input:

-20 dBm

Output:

+5 dBm
```

дальше линейность нарушается.

---

## OIP3

Параметр интермодуляции.

Особенно важен для:

* SDR
* радаров
* связи

---

# 6. LNA и перегрузка

Проблема:

Слабые сигналы:

```
-100 dBm
```

нужно усилить.

Но рядом может быть сильный:

```
+0 dBm
```

Например:

```
Основной сигнал:

-90 dBm


Помеха:

-5 dBm
```

LNA может уйти в насыщение.

Поэтому часто перед LNA ставят:

```
Antenna

 |
 |
 v

Filter

 |
 |
 v

Attenuator / Limiter

 |
 |
 v

LNA
```

---

# 7. LNA + Attenuator вместе

Очень распространённая схема:

```
             RF Input

                |
                |
              Filter

                |
                |
          +-------------+
          | Attenuator |
          +-------------+

                |
                |

          +-------------+
          |    LNA      |
          +-------------+

                |
                |

              Mixer

                |
                |

              ADC
```

Почему?

Если сигнал слабый:

```
Attenuator = 0 dB

LNA Gain = 25 dB
```

Если сигнал сильный:

```
Attenuator = 15 dB

LNA Gain = 25 dB
```

---

# 8. LNA в SDR системе

Например:

```
             RF

             |
             v

          LNA
       (20 dB)

             |
             v

          Mixer

             |
             v

          ADC

             |
             v

          FPGA

             |
             v

          FFT
```

FPGA анализирует спектр:

```
Frequency
   |
   |
   +----------------
   |      *
   |    *   *
   |  *       *
   |
   +----------------
```

Но если LNA плохой:

* шум выше
* слабые сигналы исчезают
* FFT floor поднимается

# 9. Управляемый LNA (Variable Gain LNA)

В современных системах:

```
LNA Gain:

0 dB
10 dB
20 dB
30 dB
```

Управление:

```
MCU
 |
SPI
 |
v

LNA
```

Получается:

```
AGC:

FPGA измеряет уровень

        |
        v

   меняет Gain LNA

        |
        v

стабильный ADC уровень
```

# 10. Пример Firmware архитектуры

Например:

```cpp
class ILna
{
public:
    virtual void setGain(double db) = 0;
    virtual double gain() const = 0;

    virtual ~ILna() = default;
};
```

Реализация:

```cpp
class ADL5523 : public ILna
{
public:

    void setGain(double db) override
    {
        gpio.write(encode(db));
    }

private:

    IGpio& gpio;
};
```

# 11. LNA и ADC динамический диапазон

Очень важный баланс:

Слабый сигнал:

```
RF
 |
 v
LNA +30dB
 |
 v
ADC

OK
```

Сильный сигнал:

```
RF
 |
 v
LNA +30dB

ADC overflow
```

Поэтому нужен:

```
AGC:

Attenuator
+
Variable LNA
+

```

# 12. Типичный RF приёмник

Полная цепочка:

```
                 ANTENNA

                    |
                    |
                 Filter

                    |
                    |

              Digital Attenuator

                    |
                    |

                   LNA

                    |
                    |

                  Mixer

                    |
                    |

               IF Amplifier

                    |
                    |

                   ADC

                    |
                    |

                  FPGA

                    |
                    |

                   FFT
```

---

В связке **LNA + Attenuator + ADC + FPGA + FFT** фактически строится весь современный SDR/Radar/Communication receiver. LNA отвечает за **чувствительность**, аттенюатор — за **защиту от сильных сигналов**, а FPGA уже работает с оцифрованным спектром.
