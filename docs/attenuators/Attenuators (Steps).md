Давайте подробнее разберём **шаг аттенюатора (attenuation step size)** — это один из самых важных параметров **Digital Step Attenuator (DSA)** в RF системах.

---

# 1. Что такое шаг аттенюатора

**Шаг аттенюатора** — это минимальное изменение ослабления, которое способен сделать аттенюатор.

Например:

### Аттенюатор с шагом 1 dB:

```
0 dB
1 dB
2 dB
3 dB
4 dB
...
31 dB
```

Можно выбрать только целые значения.

### Аттенюатор с шагом 0.5 dB:

```
0.0 dB
0.5 dB
1.0 dB
1.5 dB
2.0 dB
2.5 dB
...
31.5 dB
```

То есть регулировка более точная.

---

# 2. Откуда берутся эти шаги внутри микросхемы

Цифровой аттенюатор обычно построен как набор **ступеней (bits)**.

Например, 5-битный аттенюатор:

```
             RF IN
               |
               |
        +--------------+
        |              |
        |  Attenuator  |
        |              |
        +--------------+
               |
             RF OUT


Control:

BIT0 -> 0.5 dB
BIT1 -> 1 dB
BIT2 -> 2 dB
BIT3 -> 4 dB
BIT4 -> 8 dB
```

Каждый бит включает свою секцию.

---

Например:

Хотим получить:

```
6.5 dB
```

Включаем:

```
4 dB
+
2 dB
+
0.5 dB
```

Получаем:

```
BIT3 BIT2 BIT1 BIT0

0    1    1    1

= 4 + 2 + 0.5

= 6.5 dB
```

---

# 3. Почему используют бинарные шаги

Потому что это удобно реализовать цифровой логикой.

Например:

```
0.5
1
2
4
8
16
```

Это фактически:

```
0.5 × (1,2,4,8,16)
```

Как обычное двоичное число.

Например:

```
10110
```

означает:

```
16 dB
+
4 dB
+
1 dB

= 21 dB
```

---

# 4. Чем меньше шаг — тем лучше?

Не всегда.

Меньший шаг даёт:

### Плюсы:

* точнее управление уровнем
* лучше AGC
* меньше ошибка при калибровке
* лучше управление передатчиком

Например:

Для ADC:

```
Target:

-3 dBFS
```

А сигнал:

```
-1 dBFS
```

Нужно уменьшить:

```
2 dB
```

Шаг 1 dB:

```
possible:

1 dB
2 dB
3 dB
```

идеально.

---

Шаг 3 dB:

```
0 dB
3 dB
6 dB
```

уже грубо:

```
-1 dBFS

↓

-4 dBFS
```

Потеряли динамический диапазон.

---

# 5. Но маленький шаг имеет цену

Например:

## 0.5 dB step

Требуется больше RF ячеек:

```
0.5 dB
1 dB
2 dB
4 dB
8 dB
16 dB
```

Получаем:

```
31.5 dB range
```

Нужно:

```
6 бит
```

Больше:

* RF switch элементов
* площадь кристалла
* паразитные ёмкости
* потери
* цена

---

## 2 dB step

Можно сделать проще:

```
2
4
8
16
```

Всего:

```
4 бита
```

Но:

```
0
2
4
6
8
...
```

Грубое управление.

---

# 6. Пример реального выбора

Допустим:

ADC имеет диапазон:

```
0 ... -80 dBFS
```

Вход:

```
-5 dBm ... +20 dBm
```

Нужно удерживать:

```
ADC ≈ -10 dBFS
```

У нас есть:

## Вариант A

Аттенюатор:

```
0.5 dB step
0-31.5 dB
```

Можно точно держать уровень:

```
+13.7 dBm
```

---

## Вариант B

```
2 dB step
0-30 dB
```

Получится:

```
+14 dBm
```

или

```
+12 dBm
```

Ошибка:

```
±1 dB
```

---

# 7. Шаг и точность — это разные вещи

Очень важный момент.

Многие путают:

## Step size

Это:

> какое значение можно выставить

Например:

```
0.5 dB
```

---

## Accuracy

Это:

> насколько реальное значение соответствует заданному

Например:

Команда:

```
10 dB
```

А реально:

```
10.4 dB
```

Ошибка:

```
+0.4 dB
```

---

Даже если шаг:

```
0.25 dB
```

реальная точность может быть:

```
±1 dB
```

---

# 8. Шаг и частота

Ещё один важный RF момент.

Один и тот же аттенюатор:

```
0.5 dB step
```

может иметь разную точность:

На:

```
100 MHz
```

например:

```
10.0 dB
```

На:

```
6 GHz
```

может быть:

```
10.8 dB
```

Причины:

* паразитные ёмкости
* потери переключателей
* разводка PCB
* mismatch

---

# 9. Шаг в AGC системе

Типичная FPGA + MCU система:

```
              RF

              |
              v

        Digital Attenuator

              |
              v

             ADC

              |
              v

            FPGA

              |
              |
          amplitude
          detector

              |
              v

          MCU / FPGA

              |
              |
             SPI

              |
              v

        Attenuator
```

Алгоритм:

```
ADC level = -2 dBFS

Target = -10 dBFS


Difference:

8 dB


attenuation += 8 dB
```

Если шаг:

```
0.5 dB
```

можно сделать:

```
+7.5 dB
```

или

```
+8 dB
```

---

# 10. Пример из PE4312

PE4312, который мы обсуждали ранее:

Типичная структура:

```
6-bit DSA

Step:

0.5 dB

Range:

0 ... 31.5 dB
```

В Firmware:

```cpp
attenuator.set(13.5_dB);
```

превращается:

```
13.5 / 0.5

= 27
```

В двоичный код:

```
011011
```

И отправляется через SPI.

---

# 11. Практический выбор шага

| Применение                       | Типичный шаг |
| -------------------------------- | ------------ |
| Простое согласование             | 3 dB         |
| Защита входа                     | 5-10 dB      |
| RF тестовое оборудование         | 0.25-1 dB    |
| SDR приемник                     | 0.5-1 dB     |
| Radar                            | 0.5 dB       |
| HFT/низколатентный RF мониторинг | 0.5-1 dB     |
| Передатчик с точной мощностью    | 0.25-0.5 dB  |

---

Для **Firmware + FPGA + RF** наиболее интересная часть — это то, что шаг аттенюатора фактически становится частью **AGC контура**. Там уже появляются вопросы:

* как быстро менять шаги (µs),
* где хранить калибровочные таблицы,
* как компенсировать нелинейность,
* как не "качать" уровень вокруг порога,
* как синхронизировать SPI запись с FFT/ADC окнами.
