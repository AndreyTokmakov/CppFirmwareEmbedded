# GPIO — универсальные выводы микроконтроллера

Если вы только начинаете изучать ESP32, Arduino или другие микроконтроллеры, то термин **GPIO** встретится буквально в каждой статье. Понимание того, что такое GPIO и как он работает, — один из самых важных шагов в освоении микроконтроллеров.

---

# Что означает GPIO

**GPIO** расшифровывается как:

> **General Purpose Input/Output**

В переводе:

> **Универсальный программируемый вход/выход.**

Разберём это название по словам.

* **General Purpose** — универсальный, то есть может использоваться для разных задач.
* **Input** — вход.
* **Output** — выход.

Получается, что GPIO — это контакт микроконтроллера, который программа может использовать либо для получения информации извне, либо для управления внешними устройствами.

---

# Что такое GPIO простыми словами

Представьте, что микроконтроллер — это маленький компьютер.

У компьютера есть монитор, клавиатура, мышь, USB-разъёмы.

У микроконтроллера ничего этого нет.

Вместо этого у него есть десятки маленьких контактов.

Именно через них он взаимодействует с окружающим миром.

Эти контакты и называются **GPIO**.

Например, через один GPIO микроконтроллер может:

* включить светодиод;
* прочитать состояние кнопки;
* передать данные дисплею;
* получить информацию от датчика температуры.

---

# Как выглядит GPIO

На плате GPIO — это обычные контакты по краям платы.

Например, на ESP32 это выглядит примерно так.

```text
                USB

      ┌─────────────────────┐
GPIO4 │ ●                 ● │ 3V3
GPIO5 │ ●                 ● │ GND
GPIO6 │ ●                 ● │ GPIO1
GPIO7 │ ●                 ● │ GPIO2
GPIO8 │ ●                 ● │ GPIO3
      │                     │
      │        ESP32        │
      │                     │
GPIO18│ ●                 ● │ GPIO21
GPIO19│ ●                 ● │ GPIO22
      └─────────────────────┘
```

Каждый кружок — это отдельный вывод.

К большинству таких выводов можно подключать внешние устройства.

---

# Почему GPIO называется универсальным

Предположим, на вашей плате есть вывод:

```
GPIO21
```

Сегодня вы используете его для подключения дисплея.

Завтра — для кнопки.

Послезавтра — для управления реле.

Никаких изменений в самой плате не требуется.

Меняется только программа.

Именно поэтому GPIO называется **General Purpose** — универсальный.

---

# GPIO как выход (Output)

В режиме выхода микроконтроллер сам управляет напряжением на выводе.

Он может установить два состояния.

```
HIGH
```

или

```
LOW
```

### HIGH

На выводе появляется напряжение.

Для ESP32 это примерно:

```
3.3 В
```

### LOW

Напряжение отсутствует.

Практически это означает:

```
0 В
```

---

## Пример со светодиодом

Пусть светодиод подключён к GPIO5.

```
ESP32

GPIO5 ---------> LED ---------> GND
```

Программа:

```cpp
pinMode(5, OUTPUT);

digitalWrite(5, HIGH);
```

Что произойдёт?

На GPIO5 появится 3.3 В.

Через светодиод потечёт ток.

Он загорится.

Если выполнить:

```cpp
digitalWrite(5, LOW);
```

ток исчезнет.

Светодиод погаснет.

---

# GPIO как вход (Input)

Теперь представим обратную ситуацию.

Микроконтроллер уже ничего не выдаёт наружу.

Он только наблюдает.

Например, подключена кнопка.

```
3.3V
 │
Кнопка
 │
GPIO4
 │
10kΩ
 │
GND
```

Теперь программа может узнать:

* нажата кнопка;
* отпущена кнопка.

Например:

```cpp
pinMode(4, INPUT);

if (digitalRead(4))
{
    // кнопка нажата
}
```

---

# Аналогия с дверью

Представьте комнату.

На стене есть дверь.

Если дверь используется как **выход**, человек из комнаты может что-то вынести наружу.

Если дверь используется как **вход**, наоборот — кто-то входит внутрь.

Дверь одна и та же.

Меняется только направление использования.

GPIO работает похожим образом.

---

# Два возможных состояния

Обычный цифровой GPIO понимает только два значения.

```
HIGH
```

или

```
LOW
```

Это похоже на выключатель.

```
ВКЛ
```

или

```
ВЫКЛ
```

Именно поэтому цифровые схемы называют двоичными.

---

# Какие устройства можно подключать

Через GPIO подключают практически всё.

Например:

* светодиоды;
* кнопки;
* OLED-дисплеи;
* LCD-дисплеи;
* реле;
* пищалки;
* датчики температуры;
* датчики давления;
* датчики освещённости;
* GPS-модули;
* Wi-Fi-модули (если они внешние);
* Bluetooth-модули;
* сервоприводы;
* шаговые двигатели (через драйвер).

---

# GPIO и интерфейсы

Иногда кажется, что для подключения дисплея нужны какие-то особые контакты.

На самом деле часто используются те же GPIO.

Например:

```
GPIO21
```

может работать как

```
SDA
```

а

```
GPIO22
```

как

```
SCL
```

Это уже интерфейс **I²C**.

Для пользователя это всё равно остаются GPIO.

Просто программа назначила им специальную функцию.

Аналогично работают:

* SPI;
* UART;
* PWM;
* ADC (если вывод его поддерживает).

---

# Есть ли ограничения

Да.

Не каждый GPIO одинаков.

На ESP32 некоторые выводы:

* используются во время загрузки микроконтроллера (strapping pins);
* могут быть подключены к встроенной флеш-памяти или PSRAM;
* поддерживают только определённые функции;
* имеют особенности при включении питания.

Поэтому при разработке всегда полезно смотреть **схему (pinout)** именно вашей платы.

---

# GPIO — это не питание

Это одна из самых распространённых ошибок новичков.

GPIO **не предназначен для питания устройств**.

Например:

```
GPIO5
```

нельзя использовать вместо

```
3V3
```

или

```
5V
```

GPIO может выдавать лишь небольшой ток (десятки миллиампер, точное значение зависит от микроконтроллера и рекомендаций производителя). Этого достаточно для управления логическими входами или светодиодом через резистор, но недостаточно для питания моторов, мощных светодиодов или других энергоёмких устройств.

Для питания всегда используют специальные контакты:

* **3V3**
* **5V (VIN)**
* **GND**

---

# Почему GPIO — одна из самых важных тем

Практически любой проект на микроконтроллере сводится к следующей схеме:

1. Получить информацию извне через GPIO.
2. Обработать её программой.
3. Передать результат наружу через GPIO.

Например:

```
Кнопка
    │
    ▼
 GPIO (вход)
    │
    ▼
 Программа
    │
    ▼
 GPIO (выход)
    │
    ▼
 Светодиод
```

Или:

```
Датчик температуры
        │
        ▼
    GPIO / I²C
        │
        ▼
      ESP32
        │
        ▼
    GPIO / I²C
        │
        ▼
 OLED-дисплей
```

---

# Итоги

GPIO — это универсальные контакты микроконтроллера, через которые он взаимодействует с внешним миром. Один и тот же вывод можно программно настроить как **вход**, чтобы считывать сигналы от кнопок и датчиков, или как **выход**, чтобы управлять светодиодами, дисплеями, реле и другими устройствами. Кроме того, многие GPIO могут выполнять специальные функции, такие как I²C, SPI или UART.

Понимание GPIO — фундамент для работы с любым микроконтроллером. Освоив эту тему, вы сможете уверенно переходить к подключению датчиков, дисплеев, модулей связи и созданию собственных электронных проектов.
