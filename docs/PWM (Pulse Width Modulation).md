# Pulse Width Modulation (PWM) — широтно-импульсная модуляция

Если вы занимаетесь **Embedded**, **Firmware**, **микроконтроллерами**, **схемотехникой** или **RF**, то PWM (Pulse Width Modulation) — одна из самых важных технологий, которую необходимо понимать.

PWM используется практически в каждом современном устройстве:

* управление яркостью светодиодов;
* регулирование скорости двигателей;
* управление сервоприводами;
* создание аналогового напряжения без ЦАП;
* импульсные блоки питания;
* усилители класса D;
* передача мощности в RF-устройствах;
* управление нагревателями.

---

# Что такое PWM

PWM (Pulse Width Modulation) — это способ управления **средней мощностью**, подаваемой на нагрузку, путем изменения **длительности импульсов** при неизменной амплитуде напряжения.

Проще говоря:

Вместо того чтобы менять напряжение с 0 В до 3.3 В плавно, микроконтроллер очень быстро включает и выключает питание.

Например:

```
3.3V ─────┐      ┌───────┐
          │      │       │
0V        └──────┘       └───────>

```

Если включенное состояние длится долго — средняя мощность большая.

Если коротко — маленькая.

---

# Основные параметры PWM

PWM полностью описывается тремя величинами.

## 1. Амплитуда (Voltage)

Напряжение сигнала.

Например

```
3.3 В
5 В
12 В
24 В
```

Амплитуда обычно постоянная.

---

## 2. Частота (Frequency)

Сколько раз в секунду повторяется цикл.

```
100 Гц
1 кГц
20 кГц
100 кГц
1 МГц
```

Чем выше частота:

* меньше пульсации;
* выше требования к электронике;
* больше потери на переключение.

---

## 3. Duty Cycle (коэффициент заполнения)

Самый главный параметр.

Это отношение времени, когда сигнал находится в HIGH, ко всему периоду.

```
Duty = Ton / T
```

или

```
Duty = Ton / (Ton + Toff)
```

обычно выражается в процентах.

---

# Среднее напряжение

Если нагрузка "усредняет" сигнал (например двигатель, лампа, RC-фильтр), то

```
Vavg = Vcc × Duty
```

Например

```
Vcc = 12 В
Duty = 25%
```

Среднее напряжение

```
12 × 0.25 = 3 В
```

---

Еще пример

```
24 В
Duty = 70%
```

```
24 × 0.7 = 16.8 В
```

Это не означает, что на выходе действительно появляется постоянное напряжение 16.8 В — напряжение по-прежнему мгновенно переключается между 0 В и 24 В. Однако многие нагрузки из-за своей инерции или фильтрации воспринимают именно среднюю мощность.

---

# Почему двигатель крутится медленнее?

Представим двигатель.

Вместо

```
12 В постоянно
```

мы подаем

```
12 В
0 В
12 В
0 В
12 В
0 В
```

очень быстро.

Из-за:

* индуктивности обмоток;
* механической инерции ротора

двигатель не успевает останавливаться между импульсами.

Для него это выглядит как более низкое среднее напряжение.

---

# Почему светодиод светит слабее?

Глаз не способен видеть мигание быстрее примерно 60–100 Гц.

Если PWM имеет частоту

```
500 Гц
```

то человек видит только среднюю яркость.

Например

```
Duty = 10%
```

выглядит как тусклый свет.

---

# Почему PWM эффективнее линейного регулятора?

Представим два способа уменьшить мощность двигателя.

## Линейный регулятор

```
24 В
 ↓
регулятор
 ↓
12 В
 ↓
двигатель
```

Лишние

```
12 В
```

превращаются в тепло.

КПД низкий.

---

## PWM

```
24 В
↓
MOSFET

вкл
выкл
вкл
выкл
```

MOSFET работает в двух состояниях:

```
полностью открыт
или
полностью закрыт
```

В обоих состояниях потери минимальны.

Именно поэтому PWM используется почти во всех современных силовых устройствах.

---

# Откуда появляется PWM в микроконтроллере?

Практически каждый MCU имеет аппаратный **таймер (Timer/Counter)**.

Таймер:

```
считает

0
1
2
3
...
999
```

Когда счетчик достигает заданного значения, он:

* сбрасывается;
* начинает новый цикл.

Параллельно сравнивается значение счетчика с регистром сравнения (Compare Register).

Например:

```
TOP = 1000
COMPARE = 250
```

Пока счетчик меньше 250

```
HIGH
```

После

```
LOW
```

Получается

```
25%
```

---

# Пример для STM32

Предположим

```
Timer Clock = 72 МГц
```

Настроим

```
Prescaler = 71
```

Получаем

```
1 МГц
```

Теперь

```
Period = 999
```

Получаем

```
1000 Гц
```

Если

```
Compare = 500
```

то

```
Duty = 50%
```

# PWM и сервоприводы

Интересно, что сервомоторы используют PWM необычным образом.

Частота обычно фиксирована:

```
50 Гц
```

Но угол определяется **не коэффициентом заполнения**, а **абсолютной длительностью импульса**.

Например

```
1.0 мс
```

≈ 0°

```
1.5 мс
```

≈ 90°

```
2.0 мс
```

≈ 180°

Хотя коэффициент заполнения при этом составляет всего около 5–10%, сервопривод измеряет именно длительность импульса.

---

# PWM и ЦАП

Если пропустить PWM через RC-фильтр:

```
PWM
 │
 R
 │
 C
 │
Выход
```

получится почти постоянное напряжение.

Так многие дешевые устройства получают "аналоговый" выход без использования настоящего ЦАП.

---

# PWM в RF

В радиотехнике PWM применяется значительно реже, чем в силовой электронике, но встречается в нескольких важных областях:

* управление мощностью передатчиков через импульсные DC/DC-преобразователи;
* формирование огибающей сигнала в некоторых архитектурах передатчиков;
* высокоэффективные RF-усилители с ключевым режимом работы (например, классы E и F);
* цифровая генерация сигналов и последующая фильтрация в специализированных схемах.

В большинстве классических систем связи информация передается другими видами модуляции (AM, FM, PM, QAM, OFDM и т.д.), а не PWM.

# Типичные частоты PWM

| Применение            |                 Частота |
| --------------------- | ----------------------: |
| Светодиоды            |         200 Гц – 20 кГц |
| DC-моторы             |                5–30 кГц |
| Вентиляторы ПК        |                  25 кГц |
| Серводвигатели        |                   50 Гц |
| Аудио (класс D)       |         250 кГц – 1 МГц |
| Импульсные БП         |          50 кГц – 1 МГц |
| DC/DC-преобразователи | 100 кГц – несколько МГц |

# Преимущества PWM

* Очень высокий КПД.
* Простая аппаратная реализация.
* Поддерживается практически всеми микроконтроллерами.
* Отлично подходит для управления мощностью.
* Хорошо работает с MOSFET и IGBT.
* Позволяет реализовать "аналоговый" выход без ЦАП.

---

# Недостатки

* Создает электромагнитные помехи (EMI).
* Требует правильной разводки печатной платы и фильтрации.
* Может вызывать акустический шум у двигателей и катушек на низких частотах.
* После RC-фильтра остается остаточная пульсация, зависящая от частоты PWM и параметров фильтра.
